# WRO-2026-Vision2Touch
WRO 2026 Vision2Touch

## Hardware Design

This repository includes the 3D models and reference images for the main mechanical components of the Vision2Touch Braille printer.

### Components

- **Braille Grid Holder** – The holder used to support or position the Braille grid.
- **Print Head V2** – The 3D model of the printer's print head assembly.
- **Top Plate** – The model of the printer's top plate.

The `.stl` files contain the 3D models for viewing, modification and 3D printing, while the `.png` files provide visual references for each component.
